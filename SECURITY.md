# Security Policy

## Reporting a vulnerability

Do not open a public GitHub issue for a security vulnerability.

Email the maintainers listed in [CONTRIBUTING.md](CONTRIBUTING.md). If you don't get a response within seven days, email oss-community-management@datarobot.com. For questions about DataRobot products, contact support@datarobot.com.

Include the affected version, steps to reproduce, and the impact you see. We will confirm receipt, investigate, and tell you when a fix is released.

## Scope

dr-sync sends your files to a DataRobot Files container using the API token you provide through `DATAROBOT_API_TOKEN`. It never stores the token. If you find a credential in this repository or its history, report it the same way.

## More information

DataRobot's security practices are described in the [Trust Center](https://www.datarobot.com/trustcenter/).
